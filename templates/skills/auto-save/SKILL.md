# Auto-Save Skill

当任务推进、状态变化、出现风险、等待用户输入或即将停止时，自动存档技能会被触发。它要求智能体生成标准格式的 AUTO SAVE 存档块，以便后续可以随时中断并无缝恢复工作。

## 🎯 目标

确保每一步关键的状态变化都具有完全的数据诚实性和完整的上下文，能够恢复到该检查点。

## 📝 存档块规范

智能体在满足触发条件时，必须在最终输出的最后，插入一个如下格式的独立 Markdown 代码块或引用块：

```text
=== AUTO SAVE ===
做了什么:
- [简要列出当前轮次完成的具体文件修改或逻辑变更]
- [说明具体的检查点性质]

当前状态:
- [说明当前内存、测试、编译状态]
- [指明目前存在的任何临时文件或正在运行的后台进程]

下一步:
- [列出后续轮次应优先执行 of 1-3 个具体子任务]

风险:
- [说明当前存在的潜在回滚风险、依赖冲突或未决的 Governance 审核项]
=================
```

## ⚠️ 注意事项

1. 存档块内的字段必须真实无误，不得含有任何 `TODO`、`simulation` 或 `mock` 占位符。
2. 在输出最终结论时，必须把此存档块附加到内容尾部。
